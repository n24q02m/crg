# better-code-review-graph (renamed)

**This distribution has been renamed to [`n24q02m-crg`](https://pypi.org/project/n24q02m-crg/).**

`better-code-review-graph` is now a transitional stub: installing it installs `n24q02m-crg` and keeps the
legacy `better-code-review-graph` command pointing at the same entry point, so existing
`uvx better-code-review-graph` and `pip install better-code-review-graph` setups keep working. Please switch to:

```bash
uvx n24q02m-crg
pip install n24q02m-crg
```

No further releases of `better-code-review-graph` are planned beyond this stub. Source and issues:
https://github.com/n24q02m/crg
